# 4 шаг · Обиды

Android-приложение для работы с **обидами** в рамках **4 шага** 12-шаговой программы АН.

Локальный инвентарь на устройстве (Room) + **AI-голосовой / текстовый консультант** (Vapi) с воронкой А→Б→В и 13 вопросами.

## Возможности

- Список обид с прогрессом заполнения
- Колонки инвентаря (категории: люди / учреждения / концепции)
- Ситуации, типы, заметки для разбора со спонсором
- Отметка «разобрано»
- Импорт табличных данных
- AI-ассистент: сценарная воронка, контекст инвентаря, голос и текст
- Краткая памятка «Как работать»

## Стек

- **Kotlin**, Jetpack Compose, Room, Navigation
- **Vapi** — голосовой/текстовый AI-консультант
- Локальная воронка диалога и system prompt под методику АН

## Конфигурация

Ключи ассистента задаются в `local.properties` (файл не коммитится):

```properties
VAPI_PUBLIC_KEY=...
VAPI_ASSISTANT_ID=...
```

## Как открыть и собрать

1. Установите Android Studio.
2. File → Open → эта папка.
3. Заполните `local.properties` (SDK + ключи Vapi при необходимости).
4. Run ▶

APK: `app/build/outputs/apk/debug/app-debug.apk`

Приложение не заменяет спонсора, группу и литературу АН.
